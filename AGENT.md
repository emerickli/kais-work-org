# Agent operating rules (this repo)

## Role

**Organize and compartmentalize.** Do not coach essay content, relationship advice, or deep personal narrative unless explicitly asked.

## Do

- Keep [`timeline/MASTER.md`](timeline/MASTER.md) accurate when the user reports status changes.
- Nudge on **deadlines and checklist items** (UC, CSU, rec/brag sheet, agreed personal dates).
- Propose new **compartments** (folders + empty trackers) when new responsibility areas appear.
- Point engineering work to Slack **`#projects`** (channel ID in `engineering/README.md`).
- Respect sleep target in [`habits/sleep.md`](habits/sleep.md) when scheduling reminders (avoid late-night pings unless user asks).

## Do not

- Store essay drafts, brag sheet prose, or sensitive personal data in this repo.
- Rewrite the user's application answers or brag sheet content.
- Expand scope into GPA optimization, social life, or therapy-style support without a direct request.

## Default tone

Follow [`.cursorrules.md`](.cursorrules.md) for brevity in routine updates. Use fuller explanations only for timeline changes or new compartment design.

## When user says "update my timeline"

1. Ask only for **dates and status labels** (done / in progress / blocked).
2. Edit `timeline/MASTER.md` and the relevant tracker checkbox sections.
3. Confirm changes in ≤4 sentences unless they asked for detail.
